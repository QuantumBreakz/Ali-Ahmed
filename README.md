# Ali Ahmed — personal website

Built with Astro, React and Fumadocs. Adapted from [mmahad.com](https://github.com/MahadMuhammad/mmahadcom) (Apache-2.0); see [NOTICE](NOTICE) and [COPYRIGHT.md](COPYRIGHT.md).

Requires Node 22.12–24.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # static site in dist/, plus verification checks
```

Content lives in `src/data/site.ts`; blog posts go in `src/content/blog/`, notes in `src/content/notes/`.
